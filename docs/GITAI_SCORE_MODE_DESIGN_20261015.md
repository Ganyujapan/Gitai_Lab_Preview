# GITAI SCORE — モード別評価表示仕様（2026-10-15）

## 方針（今回の正式決定）

- ゲーム本編の標準背景は**自然環境**（樹皮・砂地など）を基本にし、なるべく同一環境内の色や質感の極端な混在を避ける。ただし自然の変化は残す。
- 擬態の評価対象は**そのゲームで選択されている環境画像**。環境の色・模様が変われば評価も変わる。
- 共通の採点エンジンが内部で**0～100点**の定量スコアを計算する。ユーザー向けの見せ方はモード別に分離する。
- 評価は表示・学習・標本箱用。**進化・交配・親選抜にはフィードバックしない**。人間による捕食が自然選択の条件である。

## エンタメ版（continuous_v1）

**ユーザーへの主たる採点結果は数字を隠し、6段階のランクで表示する。**

| ランク | 日本語評価 | 人間評価ラベル |
| --- | --- | --- |
| D | よく目立つ | conspicuous |
| C | 良好 | good |
| B | 優秀 | excellent |
| A | 非常に優秀 | excellent_plus |
| S | ほぼ完成 | almost_complete |
| SS | 完成域 | complete |

- ランク・日本語評価を大きく見せ、達成感を演出する。主画面に内部スコアや内訳を常時表示しない。
- 採点式とは別の**ランク変換器**で、内部スコアをランクに変換する。これにより今後の判定式更新と表示を独立させる。
- **具体的な点数境界はまだ決定していない。** 90点ならSSなどの恣意的な区切り、あるいは「上位数％だからSS」の相対評価は採用しない。人間による6段階の判定と機械スコアを、**環境ごとに**検証して決定する。
- 既存の1103件の人間評価は順序尺度。そこから直接「人間の点数」を復元したり、最適化サンプルの比率から普遍的なランク境界を作らない。
- ランクは生物個体の優劣を保証するものではなく、選択背景下での視覚的擬態の指標として扱う。

## 教育版（morph_v1）

**得点の意味や制約を学べる分析画面**として提示する。エンタメ版と同一のエンジン／環境条件を用い、評価の説明と内訳を追加する。

初期実装の優先順位：

1. 総合スコア（0～100の内部値）と、その数値が視覚比較モデルの推定値である旨。
2. 「色」「明るさ」「模様・質感」「輪郭」各0～100の成分スコア。各項目が何を計算するか短く説明する。
3. 背景画像上で蛾の位置を切り替え、**局所スコアが場所によりどう変化するか**を比較できる学習モード（設計・検証後に実装）。
4. 同じ個体の世代間・異なる個体間の比較（後続）。
5. ゆくゆくは「一致する箇所・目立つ箇所」の重ね合わせ表示。ただしアルゴリズムの画素差を**人間の知覚差と同一視しない**。

単一の総合点だけでなく、各成分の違い、計算方法、背景依存性を説明することが教育目的。

## 現在の実装状況と移行課題

- 現行ゲームのv1スコアは候補地点最大100、上位10地点の平均。個体がゲームで出現した実座標の点数とは異なる。
- 現行「GITAI SCORE」画面はエンタメ版標本箱からアクセスできる。教育版の分析UIは**まだ未実装**。
- **現行v1の採点式・採点データは凍結**し、まず同じ背景／同じ座標の人間評価との食い違いを調べて、v2の環境評価値（代表地点の集約方法、外れ値への頑健性）を確定させる。
- 自然背景を均一に近づける選択は、採点の不一致や主観的発見難度の問題を完全に解消するものではない。背景ごとにブラインド評価する。
- SSを「完成域」と呼べることを確認するには、既存のデータを用いた候補選定に加えて**未使用個体・独立盲検評価**が必要。
- ランクの境界未決定のため、この文書の作成時点では**ゲーム内UIのランク表示変更は行わない**。未検証の閾値で実装しない。

## 開発順序

1. ゲームで採用する背景画像を確定・固定する。
2. 採点対象の背景内配置点の分布、局所計算、スコア集約の仕様を決める。
3. 6段階の人間評価データで環境ごとのランク境界を較正し、独立検証する。
4. エンタメ版：数値表示をD/C/B/A/S/SSに置き換える。
5. 教育版：数値、4成分、背景上の位置別比較を公開する。
