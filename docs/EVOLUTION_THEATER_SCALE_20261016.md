# 進化シアター — 背景と蛾の表示比率修正（2026-10-16）

## 現象と修正

ゲームの標準描画領域は360×640px、蛾は38×38px（`config/konchu_univ_alpha.json`）。
進化シアターの保存画像は600×1000pxで、背景を`drawImageCover`で拡大している。

以前のシアターは6列×10行のセル占有率で蛾を決めていた：
`floor(min(100*0.78, 90*0.82)) = 73px`。

新方式はゲーム背景からの拡大率 `max(600/360,1000/640)=5/3` に合わせて
`round(38 * 5/3)=63px` とした。
これにより蛾と背景の**相対スケールがゲーム中と一致**する。
背景・6×10グリッド・ヘッダー・再生コントロール・進化アルゴリズムには変更なし。

## キャッシュ済み世代への対応

既存の進化シアター画像は端末内IndexedDB `theater_frames` にキャッシュされている。
単に描画式だけを変更すると、過去世代は73px表示のまま残る。

- `render_version:2` を導入し、旧画像を自動的に識別。
- 端末に保存された**元の60枚の蛾PNG**を使い、該当世代のシアター画像だけを無損失の世代データから再構成。
- シアターを開いたときは最初の世代を即座に表示し、後続世代を少しずつバックグラウンドで更新。
- スライダー等で古い世代を選んだ場合、その世代を優先して再生成して表示。
- 元画像が利用できない古い世代はキャッシュ済み画像を保持し、世代そのものや進化記録を削除しない。
- `theater_frames`以外の画像保存領域や親選抜・進化ロジックには影響しない。

確認用の純粋関数と自動テスト：`js/theater_scale.js`、`tests/theater_scale.test.js`。
