## SOLO v15 進化モデル

SOLO v15では、旧 `pixelwise_50_50` 遺伝を廃止し、画像そのものではなく遺伝形質と模様生成情報を継承する `trait_procedural_genotype_v2` を使用します。

- 地色の色相・彩度・明度を独立した連続形質として遺伝
- 色相は円環補間で継承し、RGB混合による灰色平均化を避ける
- 明度と模様コントラストを独立させる
- 細かな変異は比較的頻繁、大きな変異は低頻度
- 無彩色個体から色が見えるようになる「色素発現」変異を独立して持つ
- 模様はピクセルではなく「模様生成モジュール」としてまとまりごと遺伝
- 新しい模様モジュールは各子個体あたり約5%で発生
- 既存模様は位置・大きさ・濃さ・角度・周期・粗さを小さく変異
- 模様モジュールは中央斑、横帯、外縁、細斑点、縦筋、雲状まだら、環状斑、斜行筋の8種類
- 優性・劣性・不完全優性を一部の模様に適用
- 親は固定8個体ではなく、生存個体すべてを繁殖候補にする
- 第1世代は固定画像ではなく、内部の純白・無紋の親2個体から通常の遺伝・突然変異で生成した60個体
- 第1世代はリセットごとに再生成される

### プレイ感の設計目標

- 毎世代、5〜10個体程度に「前世代と違う」と分かる変化がある
- 3〜5世代で集団の変化を感じる
- 5〜10世代で色や模様の系統が見え始める
- 20〜40世代で背景への適応がはっきり見える
- 目標捕食率はおおむね40〜60%
- 速い進化を維持しつつ、グレーモザイクへの収束は避ける

## SOLO v16 調整

v15で良好だった「4秒」「明度進化」は変更しない。v16では色と模様の探索力だけを強化する。

- 色相・彩度を同じ親からひとまとまりで継承し、毎世代の平均化で色系統が早期に潰れるのを防ぐ
- 第1世代は見た目が白でも、内部の色相ポテンシャルを0〜360°に広く持たせる
- 色相の小変異・大変異、彩度変異、色素発現を強化
- 色素発現時の彩度範囲を0.16〜0.45へ拡大
- 新規模様の発生を各子個体8%へ上げ、出現時の最低コントラストを0.55へ
- 新しい模様は既存の潜在パラメータをONにするのではなく、その誕生時に新しい位置・大きさ・粗さ等を持つ
- 模様を受け継いだ子は、その模様を実際に伝えた親のパラメータを優先して継承する
- 明度関連値はv15のまま固定


## SOLO v17 調整

v16で理想的だった色相の収束方向は維持しつつ、色が明度より先に目立ちすぎる点と、彩度が高くなりすぎる点を修正。

- 4秒と明度関連パラメータはv15/v16から変更しない
- 色相の探索幅・色系統を平均化しない継承方式・第1世代の潜在色相多様性は維持
- 彩度変異率を0.32→0.18、変異幅を0.16→0.08へ低下
- 地色の彩度上限を0.32に設定
- 色素発現率を0.035→0.015へ低下
- 色素発現時の彩度範囲を0.16〜0.45→0.08〜0.24へ低下
- 大きな色相変異が起きても、その場で彩度を上げず「隠れた色相」として保持可能に変更
- 色素発現時には新しいランダム色を与えず、その系統がすでに持っている潜在色相を表に出す
- 狙いは「まず明度が背景へ収束し、その後に低〜中彩度の色が選択される」順序


## SOLO v18 調整

v17で良かった「4秒」「明度」「彩度上限」「色相系統を平均化しない継承」は維持し、色の探索再開と模様色、比較UIを改善。

- 大きな地色色相変異は、親色から最低70°〜最大180°離れる「遠距離ジャンプ」に変更
- 大きな地色色相変異が起きた子では、その瞬間の明度と彩度を維持し、色相だけを大きく変える
- これにより、紫系統へ一度収束しても、同等の明度・彩度のまま緑・青・橙など別系統を再探索できる
- 模様モジュールに独立した `pigmentHue` / `pigmentSaturation` を追加
- 模様の色も形・位置・濃淡と一緒に遺伝し、小変異・まれな大きな色相変異を起こす
- 模様の彩度は地色より派手になりすぎない範囲（概ね6〜26%、上限30%）で生成
- 世代比較の各蛾サムネイルを、ゲームと同じ背景上に表示
- 1個体拡大画面とSNS共有画像でも、蛾の背後に同じ背景を表示


## SOLO v19 調整

v18で良かった「明度→色の順に収束」「4秒」「彩度上限」「遠距離の色相ジャンプ」「模様色」は維持し、黒化個体だけ少し出やすくした。

- 大きな明度突然変異の発生率1.8%は変更しない
- 大きな明度突然変異が起きた際、15%の確率でV=0.10〜0.28の暗色域を優先して選ぶ
- 残り85%は従来通りV=0.10〜0.95から選ぶ
- 色相大変異が起きた個体でも、明度変異の抽選は独立して行うように戻した
- 狙いは、初期〜中期に「かなり黒い個体」が以前より少し見つかりやすくなること


## SOLO v20 調整

v19の進化ロジックは維持し、模様色の「見え方」だけを強化。

- 模様色の発生率・大色相変異率は変更しない
- 模様色の彩度範囲を0.06〜0.26→0.10〜0.34へ拡大
- 模様色彩度の上限を0.30→0.38へ拡大
- 地色から模様色への混合強度を1.10→1.45へ上げる
- 模様による明暗変化の反映を0.75倍にし、暗化で模様色が潰れにくくする
- 狙いは、模様の形・位置・濃淡だけでなく、模様色の違いもプレイヤーが目視で分かること

## SOLO v21 調整

砂漠背景で青〜緑系統から抜けにくい挙動を受け、大きな地色色相変異の供給量だけを増やす。

- 大きな地色色相変異率を2.5%→4.0% / 子個体へ変更
- 色相ジャンプ幅70〜180°は維持
- 明度、彩度、模様、黒化バイアス、4秒設定は変更しない
- 狙いは、明度が先に収束する流れを維持しながら、後半の色相探索を止まりにくくすること
- 樹皮背景・砂地背景の両方で同じv21進化ロジックを使用する


## SOLO v22 調整

プロジェクト正式設計との再照合を受け、親選抜と模様進化を修正。

- 親選抜を正式仕様へ戻す
  - 生存12個体以上: 生存者から12親枠を無作為・重複なしで選抜
  - 生存2〜11個体: 生存者全員を最低1枠採用し、残りを無作為に重複選抜
  - 生存0〜1個体: 繁殖不可
- 新規模様の総発生率は8%/子個体のまま維持し、模様タイプを8→12種類へ拡張
- 追加模様: chevron_pair / twin_spots / ripple_bands / radial_rays
- 模様彩度の初期発生レンジは0.10〜0.34のまま
- ただし模様彩度の進化上限を0.38→0.85へ拡張し、高彩度へ進化できる余地を解放
- 模様彩度は形状変異とは独立して20%/有効模様で小変異し、選択により高彩度・低彩度どちらにも進める
- 地色彩度の上限0.32は変更しない

## Environment × Evolution Model × Run

Previewの実験単位を、背景・進化モデル・進化履歴の3軸に分離した。

- Environment: `environments/<environment_id>/environment.json`
- Evolution Model: `data/evolution_models/<model_id>/config.json`
- Run: URLの `run=<run_id>`
- 保存単位: **Environment × Evolution Model × Run**
- 既存テスターの通常URL（樹皮/砂地 + Continuous v1 + default）は従来のIndexedDBを継続利用し、進化履歴を失わない
- 新しい組み合わせは独立した名前空間へ保存
- 第1世代は `standard_white_001` を固定Seed化し、Continuous v1では背景を変えても同じ第1世代から比較できる
- 詳細: `docs/PREVIEW_EXPERIMENT_ARCHITECTURE.md`


## 教育型 / Morph Model v1（実験モデル）

Continuous v1を置き換えず、別カートリッジとして追加した。

- 個体は2つの「モルフ・アレル」を持ち、子は父母から1つずつ受け継ぐ
- 中間値へ連続的に混ぜず、優先度（dominance rank）の高い一方のモルフが表現型として発現
- 同順位では固定Seedにより一方が発現し、毎描画で見た目が揺れない
- まれな突然変異が、体色・黒化・淡色化・模様切替・模様色・複数形質の調節変異として大きく表現型を変える
- 1個体に発現する主要模様は原則1種類とし、「型」が見えるようにする
- 突然変異で新モルフが生まれても集団全体を即時置換せず、通常の捕食・親選抜・交配を通じて増減する
- 背景画像の色や模様は進化モデルから一切参照しない
- 現在値は最初の実験用であり、診断ログとプレイ結果を見て調整する


## ChatGPT用診断ログ（サーバー送信なし）

Previewでは診断ログを外部サーバーへ送信せず、端末内IndexedDBから解析用テキストを生成してクリップボードへコピーできる。

- 左下Previewバッジの「ChatGPT用ログ」を押す
- 解析用に圧縮されたログを生成
- 「コピーする」を押してクリップボードへコピー
- ChatGPTの入力欄へ貼り付けて解析に使う
- iOS等でClipboard APIが使えない場合は、同じ画面にテキスト欄を表示し「すべて選択」→「コピー」で回収可能
- 通常の「診断ログ」ボタンは完全版JSONの保存用として維持
- ログは外部サーバーへ自動送信しない

ChatGPT用ログには、各世代の捕食数・生存数・親12枠・突然変異数・次世代個体群の色/明度概要を含む。Morph v1ではモルフを `M001`, `M002`... と識別し、突然変異した子の翌世代での生存/捕食・親採用枠数まで対応付ける。Continuous v1では大色相変異、大明度変異、色素発現、模様誕生・主要模様変異を抽出する。

本番の「ひとりでギタイ」では診断ログを収集しない方針。Preview期間の解析はこのローカルコピー機能で行う。

## モデルの役割分担（採用方針）

- **教育型 = Morph Model v1 (`morph_v1`)**
  - 高校生物の授業でも使える品質を目標にする
  - 自然選択・遺伝・突然変異・遺伝的浮動・ボトルネック・選択的スイープ・安定化選択を、プレイ結果から説明できるモデルを目指す
  - モルフそのものは離散的に保ちつつ、同じモルフ内にも小さな遺伝的個体差を持たせる二層構造を今後導入する
  - 主要な遺伝モデル調整は昆虫大学で専門家のレビューを受けた後に行う。比較テスト中は現行パラメータをむやみに動かさない
  - 固定Founder/Seedを使い、同条件で複数人の進化結果を比較できる教材利用を想定する
  - 日本語版と英語版の両方を視野に入れ、UI文言は将来言語辞書へ分離する

- **エンタメ型 = Continuous Model v1 (`continuous_v1`)**
  - 進化を短時間で見て遊ぶことを優先する
  - チャーハン等の遊び心のある背景も使用可能
  - ただし「背景が有利な変異を生成する」のではなく、ランダムな遺伝的変異 → プレイヤーの捕食 → 生存・繁殖という因果関係は維持する

昆虫大学では教育型を完成版として固定するのではなく、昆虫・進化・遺伝の専門家から意見を得る公開レビュー機会として活用する。

## 進化シアター（第一段階）

各世代の60個体を1枚の軽量スナップショットとして端末内IndexedDBに保存し、結果画面から世代順にパラパラ再生できる。

- 進化シアター用フレームは 6列×10行で60個体を同時表示する（通常の世代比較UI 3列×20行は変更しない）
- 背景はそのRunで使用しているゲーム背景
- 再生 / 停止 / 前世代 / 次世代 / 世代スライダー
- 速度: ゆっくり 1000ms / ふつう 600ms / はやい 300ms
- 各フレームに世代番号・教育型/エンタメ型を表示し、プレイ済み世代では捕食数・生存数も保持
- Environment × Evolution Model × Run の既存IndexedDB名前空間の中に保存
- リセット時は進化データと一緒に消去
- この機能導入前の過去世代画像は復元せず、保存済み世代だけを表示する。新規Run/リセット後は第1世代から連続保存
- 第一段階では動画/GIF/APNGの書き出しは行わず、ブラウザ内再生だけを実装

### 教育型の突然変異頻度（experimental_002）

- `morph_v1` の `mutation_p_per_inherited_allele` を 0.012 から **0.019** に変更
- 1個体2アレルなので、少なくとも1本が変異する理論確率は約3.76%
- 60個体では遺伝的変異イベントを持つ個体が理論上約2.26個体/世代
- 既存ログの発現率を基準に、**見た目に現れる突然変異を約1個体/世代**に近づける調整
- 変異タイプの重みと `new_morph_dominance_mutation_p=0.30` は変更しない
- 教育・展示用に進化を観察しやすく加速した値であり、自然界の実測突然変異率を表すものではない
