## 第1段階の検証
1. mainへマージした後にiPadのSafariで展示版URLを開き、オフライン用ファイル保存済みの表示を確認する。
2. 「ホーム画面に追加」→「Webアプリとして開く」。以後、**ホーム画面の展示版アイコン**から起動する。
3. 各モードを1世代以上プレイ。世代比較／開始画面の「次の人へ交代」から展示トップに戻る。
4. iPadを機内モードにし（Wi-Fiもオフと確認）、ホーム画面アイコンで起動。両モードでプレイ、世代を進める。
5. アプリ終了・端末再起動後に同じアイコンから再開し、世代番号が変わっていないことを確認する。
6. Safariサイトデータ削除、Webアプリ削除、ストレージ不足、iPad初期化は進化データ消失の原因になる。展示前に必ずJSONバックアップ機能を実装・試験する。

## 補足
WebKitの永続ストレージ要求はベストエフォートであり、データ消失を保証して防ぐものではありません。
PWAのホーム画面アプリとSafariタブは保存領域が別になることがあります。展示中は同じホーム画面アイコンのみ使用します。
