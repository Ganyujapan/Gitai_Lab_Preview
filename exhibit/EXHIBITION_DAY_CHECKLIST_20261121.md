# 昆虫大学2026：ギタイラボ展示当日のiPad運用手順

**予定日：2026年11月21日／使用端末：ホーム画面に追加した展示版PWA（iPad縦置き）**

これはスタッフ用の簡易手順です。端末での合格判定は [Issue #135](https://github.com/Ganyujapan/Gitai_Lab_Preview/issues/135) と [iPad受入表](./IPAD_ACCEPTANCE_20261029.md) が優先です。GitHub自動テストの成功を実機合格と読み替えないでください。

> **最重要：本番開始後は、進化データを絶対に初期化しない。** PWA削除・再インストール、SafariのWebサイトデータ削除、端末の初期化は禁止。ゲーム画面以外の保存領域を勝手に操作しない。

## 1. 開場前（通信を使える場所で）

- [ ] 盗難防止スタンドと磁気充電器を固定し、iPadの充電表示・画面の縦向き・音量を確認する。
- [ ] 必ずホーム画面の**展示版PWA**を起動する。通常SafariやChatGPT内ブラウザとは保存領域が異なる場合がある。
- [ ] モード選択で「アプリ版」と「✓ オフライン用ゲームファイルを保存済み」「✓ 永続ストレージが許可されています」を確認する。版番号をスタッフメモに記録する。
- [ ] インターネット接続中に最新版が必要なら、**他のゲーム画面を閉じ、世代保存とバックアップ準備／復元が終了してから**、モード選択→「管理者用」→「最新版を確認（インターネット接続時）」→表示された場合だけ「ダウンロード済みの更新を適用」。適用後はアプリ版とオフラインファイル保存表示を再確認する。更新前後に進化データが同じ世代であることを確認する。
- [ ] **展示前のテストデータ初期化は、本番開始前の一度きり。** 保存する必要がある記録がないと確認できた場合のみ実行する。管理者用で対象モードを選択し「初期化対象を確認（読み取り専用）」→件数・世代・対象名を確認→「確認したモードのテストデータを初期化」→二段階確認。隠れるギタイ／目立つギタイはそれぞれ別操作。途中や部分失敗では画面指示に従い、勝手に別の初期化・復元を試さない。
- [ ] 初期化後は隠れるギタイが新しい第1世代から、目立つギタイが無捕食の準備20世代を経た第21世代から始められることを確認し、必要ならゲーム画面を閉じてホームへ戻る。**この確認も進化を進めるため、記録が残ることに注意。** 本番開始後にこれを消去しない。
- [ ] オフライン確認：機内モードをON、Wi-FiもOFFにして展示版PWAを開き、タイトル→モード選択→両モードの入口に進めることを確認する。必要な世代試験は開場前までに済ませる。実機受入未完了の項目を合格と記録しない。

## 2. 来場者の交代

- 進化データは**同じiPadの次の来場者へ引き継ぐ**。来場者がリセット操作をする必要はない。
- 1人につき5世代。途中で交代する場合は**世代の結果画面**にある「次の人へ変わる」を使用し、進化の保存が成功してモード選択へ戻ったことを確認する。
- 5世代後は「次へ（進化シアター）」から自動再生。再生が終わっても最後の蛾を表示し、**「もう一度再生」**で何度でも振り返れる。「次の人へ →」を押したときだけ交代する。
- 目立つギタイは**交代のときだけライフ10に戻る**。同じ人が続ける途中はライフを引き継ぐ。
- 「保存中…」やエラー表示がある間は、連打・別モードでの初期化・他の画面での操作をしない。保存失敗や世代不一致のときはスタッフに知らせ、世代番号と表示メッセージを記録する。復旧のためにデータを消去しない。

## 3. 環境音が止まった・鳴らない場合

1. iPadの音量、消音状態と実際のBGM ON/OFF設定を確認。音声は最初のユーザー操作が必要な場合がある。
2. ゲーム中の世代保存が終わっていることを確認し、通常の操作でトップへ戻る。改めて音声の再生操作を試す。
3. 直らなければ、**世代番号・オフライン状態・表示された「♪ 音源エラー」等の文言**を記録する。必要なら世代保存後にPWAを閉じて開き直す。
4. 音が出ないからといって、PWAの削除、サイトデータ消去、再インストール、試験用バックアップ復元はしない。BGMの複数周再生はiPad実機受入の残件である。

## 4. データ保護・バックアップ

- 展示中に別のSafariタブや管理画面から同じ実験を進めたり、復元したりしない。
- 管理者用の「保存状況を診断（読み取り専用）」は件数・現世代60匹のキー確認用で、バックアップを作成しない。
- 保存が必要なときは**ゲームと世代保存を終了した状態で**、各モードの現行**v1 JSON**を準備→別のタップで「準備したJSONを共有シートで保存」→iPad「ファイル」で存在確認→「保存したJSONを検証する（読み取り専用）」で再選択。ファイル保存開始だけでは成功扱いにしない。
- データ量が上限を超えてバックアップ準備が拒否されたら、**エラー内容・世代・件数を記録し、本番データを消さない**。大容量v2の本番書出し・復元は [Issue #163](https://github.com/Ganyujapan/Gitai_Lab_Preview/issues/163) の安全ゲートが完了するまで利用しない。
- 初期化・JSON復元・診断用の破損試験は展示本番中には行わない。

## 5. 閉場後

- [ ] 両モードの現在世代、ライフ（目立つギタイ）、アプリ版を記録する。
- [ ] 未完了の世代保存やバックアップ準備がないことを確認する。
- [ ] 必要なv1 JSONバックアップをモードごとに保存し、保存済みファイルを再選択して検証する。ファイルを勝手に上書き・削除しない。
- [ ] iPadの残容量、充電・発熱、音声トラブル、エラー表示の有無を記録する。
- [ ] **進化データは翌日以降のためにそのまま残す**。閉場時の自動／手動初期化は不要。

## 6. 本番前にiPadで別途確認すること（自動テストでは代替不可）

完全オフラインでの目立つギタイ、5世代後の交代と次来場者カウント、PWA終了・再起動後のDNA/画像/ライフ保持、環境音2周以上、最新進化シアターの繰り返し再生、初期化後のゲーム再開、磁気給電・発熱・スリープ復帰、合成100/1000件の処理速度、端末の空き容量。結果は [Issue #135](https://github.com/Ganyujapan/Gitai_Lab_Preview/issues/135) に記録する。
